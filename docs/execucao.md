# Execução do projeto

## 1. Criar e alimentar o notebook

1. Abrir https://notebook.google.com/ na própria conta e criar um notebook com o título “Segurança digital pessoal”.
2. Revisar a curadoria em `docs/fontes.md`, incluindo vídeo e página web.
3. Adicionar as fontes aprovadas. Para PDFs, baixar do site oficial se a importação por URL falhar.
4. Conferir se o conteúdo foi importado corretamente; se o vídeo não tiver transcrição compatível, registrar a limitação e escolher outro vídeo após revisão.
5. Registrar quais itens entraram e quais foram rejeitados.
6. Configurar as instruções do chat com `prompts/diretriz.md`; se a interface não oferecer configuração persistente, enviar a diretriz no chat e registrar como foi aplicada.

## 2. Testar e aprender

Executar Q01 a Q08 de `prompts/perguntas.md`. Abrir as citações e preencher `docs/validacao.md`. Fazer o quiz antes de consultar o gabarito e registrar os erros e o que foi aprendido.

## 3. Gerar e baixar os materiais

Usar `prompts/estudio.md` para criar os materiais que a conta disponibilizar. Priorizar mapa mental e apresentação ou guia. Salvar exportações reais em `materiais/` e atualizar o inventário com nome, formato e revisão realizada.

## 4. Compartilhar e publicar

Revisar os conteúdos para remover dados pessoais. Compartilhar o notebook com a permissão necessária para visualização e testar o endereço em outra sessão. Se a conta restringir o compartilhamento, registrar a limitação real.

Adicionar o link ao README e substituir os estados pendentes pelos resultados observados. Manter apenas links para arquivos existentes. Confirmar que o repositório está público e pertence à própria conta. Enviar à DIO o endereço do repositório.

## Critério de conclusão

O projeto estará pronto quando houver um notebook acessível, fontes realmente importadas, respostas verificadas com evidências e materiais reais exportados. Esta preparação por si só não conclui o desafio.
